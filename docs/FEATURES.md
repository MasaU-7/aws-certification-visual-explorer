# 欲しい機能一覧

コンセプト: **AWSを読むのではなく、動かして理解する。**

## コア体験

| ID | 機能 | 説明 | MVP |
|----|------|------|-----|
| F01 | AWS World マップ | カテゴリを3D空間に配置し、「今どこにいるか」を常に可視化 | ✅ |
| F02 | 資格フィルター | 資格選択で試験範囲だけを点灯、対象外は薄暗く | ✅ SAAのみ |
| F03 | ズーム階層 | 資格 → 概念/カテゴリ → 構造 → 挙動 へ掘り下げる | ✅ カテゴリ→サービス |
| F04 | サービス関係ビュー | クリックで関連サービス・シナリオを線/チップで示す | ✅ 簡易 |
| F05 | 挙動アニメーション | リクエスト流、スケールアウト、ブロック等を視覚化 | Phase 4 |
| F06 | VPC 都市ビュー | AZ / Public / Private を空間として表現 | Phase 3 |
| F07 | Scenario Mode | 空の空間にサービスを配置し構成を完成させる | Phase 5 |
| F08 | Architecture Mode | 完成構成を眺めながら流れを再生 | Phase 5+ |
| F09 | 図集モード | 「〜を利用した構成」ギャラリー | Phase 6 |
| F10 | 多資格対応 | CLF / DVA / SOA / SEC 等 | 後続 |

## やらないこと（意図的）

- 用語辞典・長文レッスン
- クイズ / 進捗トラッキング中心の LMS
- ログイン / ユーザーDB / 課金
- AWS API 実接続（学習コストと無料枠制約のため MVP 外）
- バックエンドサーバー

## 設計原則

1. **説明より挙動** — テキストは最小限
2. **サービス図鑑にしない** — 「世界の中での役割」を見せる
3. **資格はフィルター** — 世界は一つ、範囲だけ切り替える
4. **データは再利用** — 1サービス定義がマップ・3D・Scenario に流用
